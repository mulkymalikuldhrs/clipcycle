# Founder OS Templates — Complete Pack

## What's inside
1. **Solo Founder Daily OS** — daily focus, time blocks, shutdown ritual, weekly review
2. **Content Pipeline Tracker** — idea→publish kanban with velocity tracker
3. **Trading Journal Lite** — pre-trade checklist, R-multiple logging, QNA-compatible

## Install
1. Download this zip
2. Unzip
3. In Notion: New Page → Import → Markdown → select any .md file
4. In Obsidian: copy .md files into your vault folder

## Usage
- Solo Founder Daily OS: duplicate weekly, fill at start of each day
- Content Pipeline Tracker: duplicate per content calendar week
- Trading Journal Lite: one copy per month, log every trade
